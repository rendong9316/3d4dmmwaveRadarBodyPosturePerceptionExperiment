德州仪器TI
毫米波级联成像雷达射频评估模块
MMWCAS-RF 评估模块 (EVM) 是 TI 提供的一款采用 AWR2243 四器件级联阵列的感应解决方案。
在这一级联雷达配置中，单个主器件在所有四个器件之间分配 20GHz 的本机振荡器 (LO) 信号，使这四个器件作为单个射频收发器运行。
可支持多 12 个发射 (TX) 和 16 个接收 (RX) 天线元件。在 TX 波束形成、波束控制和多输入多输出/单输入多输出 (MIMO/SIMO) 等用例中，与单器件系统相比，大量天线元件均可实现较高的信噪比和出色的角分辨率。
MMWCAS-RF-EVM
MMWCAS-DSP-EVM
MMWCAS-DSP 设计为级联成像雷达系统奠定了处理基础。
级联雷达设备可支持前端远距离雷达 (LRR) 波束形成应用以及角级联和侧级联雷达和传感器融合系统。
此 EVM 设计为有资质的开发人员提供了设计材料，供开发人员创建用于开发和测试高级驾驶辅助系统 (ADAS) 的有效软件评估平台。

特性：
具有 4 个雷达处理 SIMD 加速器的高性能 TDA2x 器件
以太网和 PCIe 连接，分别用于控制和数据

研究背景
1.1
[Notes]: 传统的跌倒检测手段有很多问题：可穿戴设备老人不愿意戴，摄像头存在隐私泄露风险，而且都受光照和天气影响。毫米波雷达完美解决了这些问题：它是非接触式的，不侵犯隐私，全天时全天候都能工作，成本也很低。
除了跌倒，还有很多别的人体运动的识别可用于智能家居、安防、校园霸凌等多种场景。

国内外研究进展
1.2
萌芽探索阶段（1990-2010 年）：微多普勒效应的发现与基础应用 

核心突破：人体运动微多普勒特征的首次观测与建模
代表文献 1：建立人体微多普勒数学模型
Micro-Doppler Effect in Radar: Phenomenon, Model, and Simulation Study (IEEE Transactions on Aerospace and Electronic Systems, 2006)

系统建立人体运动微多普勒效应的数学模型，推导了不同身体部位的微多普勒频率公式，证明了微多普勒特征可用于人体识别。
代表文献 2：将机器学习用于雷达动作识别
Human Activity Classification Based on Micro-Doppler Signatures Using a Support Vector Machine  (IEEE Transactions on Geoscience and Remote Sensing, 2009)

该文章将机器学习算法（SVM）用于雷达人体动作识别，提取了 6 种手工微多普勒特征，实现了 8 类动作的分类。

=== Slide 26 ===
============================================================
国内外研究进展
1.2
快速发展阶段（2010-2021 年）：深度学习与 3D 雷达的普及 

核心突破：从手工特征到深度学习自动特征提取
代表文献 1：将 CNN 用于雷达微多普勒谱识别
 mm-Pose: Real-time human skeletal posture estimation using mmWave radars and CNNs(IEEE sensors journal, 2020)

实现实时雷达人体骨架估计，开创性提出毫米波雷达+CNN实现人体15关节骨架估计，可在真实环境中实时跟踪人体姿势。
代表文献 2：将点云深度学习用于雷达人体姿态估计
 mmmesh: towards 3d real-time dynamic human mesh construction using millimeterwave

基于PointNet++，提出了实时 3D 人体网格重建系统，通过分析毫米波生成的稀疏 3D 点云，结合深度学习框架同时估计人体位置、姿态和体型，并能处理点云稀疏、遮挡和身体部位缺失等问题。

PointNet系列算法已经发展出了很多版本，各有特点，大家可自行查找资料学习使用。

国内外研究进展
1.2
前沿突破阶段（2021 年至今）：4D 成像雷达与多模态融合

 核心突破：俯仰角分辨实现真正 3D 空间感知，多模态融合解决单模态局限性
代表文献 1： 4D 雷达点云人体运动识别
Multi-Human Activity Recognition Based on Sequential 4D Point Clouds Using Frequency-Modulated Continuous Wave Radar

使用4D毫米波雷达点云进行了多人人体运动识别，并相比基线方法，取得更优的识别准确率。
代表文献 2：雷达+视觉特征级融合的较新架构
CRAFT: Camera-Radar 3D Object Detection with Spatio-Contextual Fusion Transformer(AAAI, 2023)

提出一种特征级雷达+视觉融合的3D 目标检测方法，将雷达与传感器与视觉传感器的优势进行互补，取得当时最优性能。

什么是微多普勒效应？
刚体目标的所有部分都以相同的速度运动，因此其回波只有一个多普勒频率。
         人体是由多个运动部分组成的非刚体，躯干、手臂、腿、头等部位的运动速度和方向各不相同，每个部位都会产生自己的多普勒频率，这种现象称为微多普勒效应。
         微多普勒效应是毫米波雷达能够识别人体动作的核心物理基础，不同动作的微多普勒特征具有显著差异。

3.2                  时频分析
为什么人体运动感知必须用时频分析
傅里叶变换的致命局限性
传统傅里叶变换 (FT) 只能给出信号的全局频率分布，完全丢失了时间信息。对于平稳信号（如正弦波），傅里叶变换足够用。但人体雷达回波是典型的非平稳信号。
如果直接对整段动作信号做傅里叶变换，得到的只是整个动作过程的平均频率分布，完全无法反映动作的动态过程，也就无法区分不同动作。
时频分析的核心价值
时频分析的本质是在时间和频率两个维度同时观察信号，它能告诉我们：什么时间出现了什么频率的信号、每个频率分量的能量随时间如何变化。

五、模型构建
ResNet18
传统的卷积神经网络包括输入层、卷积层、激活函数、池化层、Dropout层和全连接层。随着神经网络的层数加深，提取的特征越高级，性能也就越好，但传统的卷积神经网络当层数过深时，会面临网络退化、梯度消失、梯度爆炸等问题，使得高层网络的性能反而不如浅层网络。
ResNet的创新点就在于引入了批次归一化层而弃用Dropout层来解决梯度消失和梯度爆炸问题。引入残差结构来解决网络退化问题。
ResNet18有18层深，包括卷积层、残差块和全连接层。这个“18”指的是网络中权重层的数量。
前17层用于特征提取，最后一层全连接层用于分类识别。
RetNet网络的基础是残差块，由多个残差块组成，每个残差块包含两个或多个卷积层，以及一个或多个恒等连接。后续可以对单残差块进行处理，如加入池化，批量化归一等各种操作。

视觉模态信号处理思路：
关于从视觉进行人体姿态识别方面，该方向发展已经非常成熟，要想进行雷达与视觉的特征级融合，首先要提取视觉模态的人体姿态特征，可选的特征包括图像特征或骨架关键点特征。

数据预处理：根据人体姿态数据集（共80帧），读取并统一格式，确认每个样本对应的是一个完整动作序列而不是单帧图像，然后进行灰度归一化处理；
图像特征提取：采用目前较成熟且实现简单的 CNN 或轻量级视频识别网络，例如 ResNet18、MobileNet、3D CNN、TSM 等，对每一帧或连续帧片段提取人体姿态、轮廓和外观特征；
骨架关键点特征提取：使用 MediaPipe、OpenPose、HRNet 等人体关键点检测方法，从连续80帧视觉图像中提取人体关键点坐标，并将其整理为骨架序列

雷达与视觉时间对齐思路：
雷达数据和视觉数据均为80帧，雷达数据在5.008s左右范围内采集了80帧，视觉在5.2s左右时间内采集了80帧，在采集时，视觉比雷达的开始采集时间还慢了有0.5s左右的短暂不固定时间由于雷达和视觉有0.5-1s时间差，且这种时间差不固定，故我们推荐几种方案：
1、忽略时间差，假设两者是同步的，不用对齐，直接进行各自模态的数据输入网络，进行特征级融合。在特征融合后、识别分类前添加时序模块，再输出动作类别。

2、分别基于雷达点云和视觉数据，提取人体骨架或运动表征，将两种模态转换到统一特征空间。然后通过运动强度曲线互相关、关键帧匹配等方法估计两模态的时间偏移，实现帧级对齐后再进行特征级融合识别。
